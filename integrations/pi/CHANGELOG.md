# Grasshopper for Pi

## [2.14.0]

- Install with `pi install git:github.com/MylesMCook/grasshopper`.
- The footer shows whether Grasshopper memory loaded.
- Memory reloads after compaction, and `/grasshopper refresh` reloads it any time.
- `/grasshopper` shows `grasshopper check`; `/grasshopper connect <server link>` connects a machine that runs only Pi.
- `/remember <text>` saves something on purpose; `/handoff` writes this project's handoff.
