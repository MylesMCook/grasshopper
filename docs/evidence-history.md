## Backend scenarios
- Given project A uses bun and project B uses npm, scoped search/get/export/context never mix them, even before ranking limits.
- Given a confirmed global preference, context returns it without semantic ranking or decay; a Windows fact never becomes macOS context.
- Given a correction with the expected revision, all readers see the new content, and can inspect or explicitly restore the old revision. An observation cannot replace confirmed content.
- Given concurrent corrections from different harnesses, one succeeds and one conflicts. Identical request replay returns the original acknowledgement; changed payload under the same key fails.
- Given an active service, newly embedded or corrected content is available to semantic recall immediately; qualification beyond character 200 survives full retrieval.
- Given archive or restore, obsolete revisions stay out of recall and the operation is reversible.
- Given missing/invalid authentication or an index request, the remote memory-only surface rejects it.
- Given a legacy database, migration preserves IDs/content and leaves unknown-scope records out of normal context. Backups restore into a usable original database.
