Set up Grasshopper.

Start one private server. Connect Codex, Cursor, or Claude Code to it.

1. Download the server

Choose the machine that will hold your memories.

Mac · Apple silicon

Download Mac server

Windows · x64

Download Windows server

Linux · x64

Download Linux server

These archives are unsigned. Check their SHA-256 sums on the release page before opening them.

2. Start it

Extract the zip and run this command from its folder:

Mac or Linux

./bin/grasshopper-server --quickstart

Windows PowerShell

.\bin\grasshopper-server.exe --quickstart

Grasshopper creates an empty database and prints its local viewer address and token-file path. Open that address to see your memories. Keep the token private. For agents on other machines, first give this server a private HTTPS address; do not expose it publicly.

3. Connect Codex or Cursor

Codex

codex plugin marketplace add MylesMCook/grasshopper --ref marketplace
codex plugin add grasshopper-macos@grasshopper-marketplace

Use windows or linux in place of macos on those systems.

Cursor

agent plugin marketplace add https://github.com/MylesMCook/grasshopper.git --git-ref marketplace

Install your OS entry in /plugins, or use Customize → Plugins in the IDE.

Ask the agent: Use the connect-grasshopper skill. Give it this server's /mcp address and the path to a token file on that machine. Never paste the token into chat. Review Codex hooks or approve Cursor MCP when prompted.

Using Claude Code? Follow the Claude Code option in the setup guide.

4. Check it

Save one real preference with an agent. In a fresh session, ask another agent what arrived before tool use. Open Memory view to inspect the record.
