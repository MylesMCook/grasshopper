Connect your agents.

Install Grasshopper on each machine. One private server keeps the memories.

1. Install a connector

Codex

codex plugin marketplace add MylesMCook/grasshopper --ref marketplace
codex plugin add grasshopper-macos@grasshopper-marketplace

On Windows or Linux, use its matching plugin entry.

Cursor

agent plugin marketplace add https://github.com/MylesMCook/grasshopper.git --git-ref marketplace

Install your OS entry in the Plugins menu, or in the IDE under Customize → Plugins.

Claude Code

Download your OS's client archive, verify it against SHA256SUMS, and extract it. Then run:

./bin/grasshopper connect --agents claude --url https://your-private-server

On Windows, use grasshopper.exe.

2. Connect once

Ask the agent: Connect Grasshopper. On a new machine, give it your private server link when asked. Open its approval link in your already-connected memory view, match the device and code, then approve. No token goes through the agent.

Codex may ask you to trust its hook and allow network access to your private server; Cursor may ask you to enable Grasshopper MCP. Start a fresh session after that native step. The connection is reused by agents on this machine.

Need a server?

Download a server archive and follow the short hosting guide. Keep it private; other machines need private HTTPS. Check the release's SHA-256 sums before running it.
