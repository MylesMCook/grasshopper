Start your own copy.

Download once. Run one command. Grasshopper creates an empty, private memory store on your machine.

1. Download your server

Choose the machine that will hold your memories. These are unsigned preview builds; review your operating system's warning before opening one.

Mac · Apple silicon

Download Mac server

Windows · x64

Download Windows server

Linux · x64

Download Linux server

The release page includes SHA-256 checksums. The bundle contains the local model and runtime; no compiler is needed.

2. Run it locally

Extract the zip. In a terminal inside the extracted folder, run the command for your system:

Mac or Linux

./bin/grasshopper-go-server --quickstart

Windows PowerShell

.\bin\grasshopper-go-server.exe --quickstart

Grasshopper prints a local memory-view address and the path to your access-token file. Open the address on that machine, then enter the token from the file. The token is never printed by the server. Stop the server with Ctrl-C; run the same command to reopen your memories. A partial setup fails rather than resetting existing files.

3. Connect an agent

Use the client guide to connect Codex, Cursor, or Claude Code to this server. Each agent uses the same authenticated records. To share across machines, first add a private HTTPS route to the host; quickstart only listens on this machine.

Your server owns the token and memories. Memory view opens the view on a server you choose. This public website never handles your token.
