Set up Grasshopper.

Start one private server. Connect Codex, Cursor, or Claude Code to it.

1. Download the server

Choose the machine that will hold your memories.

Mac · Apple silicon

Download Mac server

Windows · x64

Download Windows server

Linux · x64

Download Linux server

These archives are unsigned. Check their SHA-256 sums on the release page before opening them.

2. Start it

Extract the zip and run this command from its folder:

Mac or Linux

./bin/grasshopper-server --quickstart

Windows PowerShell

.\bin\grasshopper-server.exe --quickstart

Grasshopper creates an empty database and a master token. Open its memory view and connect once with that token. Keep it on the server. For other machines, give the server a private HTTPS address; do not expose it publicly.

3. Connect an agent

Codex

codex plugin marketplace add MylesMCook/grasshopper --ref marketplace
codex plugin add grasshopper-macos@grasshopper-marketplace

On Windows or Linux, choose the matching plugin entry instead of the Mac entry.

Cursor

agent plugin marketplace add https://github.com/MylesMCook/grasshopper.git --git-ref marketplace

Install your OS entry in Agent CLI's Plugins menu or Customize → Plugins in the IDE. On Windows Agent CLI, keep the default user-level MCP location.

Claude Code

Download and verify the client archive for this machine. Extract it, then connect. Mac or Linux:

./bin/grasshopper connect --agents claude --url https://your-private-server/mcp

Windows PowerShell:

.\bin\grasshopper.exe connect --agents claude --url https://your-private-server/mcp

In your connected memory view, open Connect another device and copy the address. For Codex or Cursor, ask the agent: Use the connect-grasshopper skill with this address: [paste address]. Approve the matching device and code in the same view. No master token is copied. Review Codex hooks or approve Cursor MCP when prompted.

4. Check it

Save one real preference with an agent. In a fresh session, ask another agent what arrived before tool use. Open Memory view to inspect the record.

Update or remove a connector · Backup and recovery

Update or remove a connector

Connector changes do not delete your server memories. Keep the old package until a fresh session reads a known memory.

Codex

Update the marketplace, then reinstall your OS entry:

codex plugin marketplace upgrade grasshopper-marketplace
codex plugin add grasshopper-macos@grasshopper-marketplace

For Windows or Linux, use its matching entry. To remove the Mac entry and marketplace:

codex plugin remove grasshopper-macos@grasshopper-marketplace
codex plugin marketplace remove grasshopper-marketplace
Cursor

Agent CLI can keep an old Git snapshot. Remove and re-add the marketplace, then reinstall your OS entry in the Plugins menu:

agent plugin marketplace remove grasshopper-marketplace
agent plugin marketplace add https://github.com/MylesMCook/grasshopper.git --git-ref marketplace

To remove Grasshopper, uninstall it in the Plugins list. If you enabled its MCP entry, disable it:

agent mcp disable grasshopper
Claude Code

Extract the new client beside the old one and rerun setup with your original server options:

./bin/grasshopper setup --agents claude --update

To remove the plugin and marketplace:

claude plugin uninstall grasshopper@grasshopper-local
claude plugin marketplace remove grasshopper-local

Updates reuse this machine's saved server address and device token. Check a fresh session before removing the old package. Disconnect a device in the server's memory view when you no longer use it. Server updates and backups are separate.
