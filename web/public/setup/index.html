Start your own copy.

Start a private server, then connect the agents you use. Your memories stay on that server.

1. Download your server

Choose the machine that will hold your memories. The archives are unsigned, so your operating system may ask you to confirm before opening them.

Download Mac server

Windows · x64

Download Windows server

Linux · x64

Download Linux server

The release page includes SHA-256 checksums. The bundle includes the model and runtime; no compiler is needed.

2. Run it locally

Extract the zip. In a terminal inside the extracted folder, run the command for your system:

Mac or Linux

./bin/grasshopper-server --quickstart

Windows PowerShell

.\bin\grasshopper-server.exe --quickstart

Grasshopper prints a local memory-view address and the path to your access-token file. Open the address on that machine, then enter the token from the file. The token is never printed by the server. Stop the server with Ctrl-C; run the same command to reopen your memories. A partial setup fails rather than resetting existing files.

3. Connect an agent

Download the client on each agent machine: Mac, Windows, or Linux. Extract it and run one command from that folder:

Mac or Linux

./bin/grasshopper setup

Windows PowerShell

.\bin\grasshopper.exe setup

That checks a server on the same machine and installs Codex and Cursor. Add Claude Code with --agents codex,cursor,claude. For another machine, use its private HTTPS address and a securely copied token file; the client guide shows the exact command. Codex and Cursor may ask you to approve their new hooks or MCP source.

Updating? Keep the old folder, extract the new one, and run setup --update. Make a checked backup before replacing a server binary. Memory view opens a server you choose. This public site never handles your token.

4. Try one real memory

A new server starts empty. Tell one agent a preference or project decision you actually want kept. Ask for its record ID and revision. In a fresh session with another agent, ask what it remembers. Use Memory view to inspect it.
