Set up Grasshopper

About 10 minutes

1 · Server

Download the macOS server (Apple silicon) and check it against SHA256SUMS.

Unzip it, open a terminal in that folder and run:

./bin/grasshopper-server --quickstart

Leave it running. It prints where your token is. Then open the memory view on this machine and sign in.

Using it from other machines?

Put the server behind a private HTTPS proxy such as Tailscale Serve, then add --allowed-proxy-host <name>.ts.net:443 to the command above. See the hosting guide.

2 · Plugin

Codex

codex plugin marketplace add MylesMCook/grasshopper --ref marketplace
codex plugin add grasshopper-macos@grasshopper-marketplace

Cursor

agent plugin marketplace add https://github.com/MylesMCook/grasshopper.git --git-ref marketplace

Then install grasshopper-macos from Plugins (IDE: Customize → Plugins).

Claude Code

claude plugin marketplace add MylesMCook/grasshopper#marketplace
claude plugin install grasshopper-macos@grasshopper-marketplace

Approve the three read tools when Claude Code asks.

Pre-approve them instead

Use the client archive in place of the two commands above. Use one route or the other.

./bin/grasshopper connect --agents claude --url https://your-server.tailnet.ts.net

Replace the example with your server address.

3 · Connect

In a new agent session, say:

Connect Grasshopper

Then approve it in your memory view under Agents, if the code matches. No token passes through the agent.

Not working?

Codex may ask you to trust its hook and allow network access; Cursor may ask you to turn on Grasshopper MCP. Allow it, then start a new session. Check the server is still running and the address is right.

4 · Try it

Tell your agent a preference. Start a new session and ask about it.
