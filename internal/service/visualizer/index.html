Connection

Paste the owner token from your server’s access-token file. Never share it with an agent.

Where is my token?
  • macOS: ~/Library/Application Support/Grasshopper/access-token
  • Windows: %APPDATA%\Grasshopper\access-token
  • Linux: ~/.config/Grasshopper/access-token, or $XDG_CONFIG_HOME/Grasshopper/access-token if XDG_CONFIG_HOME is set.

With --data-dir, use access-token inside that directory. A manual server uses --token-file. For a custom path or a server you do not run, ask its operator for the owner token file location using a private channel. A device token cannot sign in here.
