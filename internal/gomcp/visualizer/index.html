Connection

Ask the person who runs your Grasshopper server for its owner access token using a private channel. If you run quickstart, the default owner token file is ~/Library/Application Support/Grasshopper/access-token on macOS, %APPDATA%\Grasshopper\access-token on Windows, or ~/.config/Grasshopper/access-token on Linux ($XDG_CONFIG_HOME/Grasshopper/access-token if XDG_CONFIG_HOME is set). With --data-dir, use access-token inside that directory. For a manual server, use the file selected by --token-file. If the installation uses custom paths, ask its operator for the owner token file location. A device token cannot sign in here. Never paste the token into an agent chat. This browser stays signed in for 7 days; Sign out forgets this browser. Sign out everywhere ends all owner browser sessions.
