# Grasshopper

Keep the few things your coding agents should remember: explicit preferences, project decisions, verified lessons, and short handoffs. Codex, Cursor, and Claude Code connect to one private server.

## Get started

1. [Start your server and connect an agent](SETUP.md).
2. Ask it to save one preference or decision you want kept.
3. Open a fresh session and ask what Grasshopper remembered.

[See how it works](https://usegrasshopper.com/) · [Open your memory view](https://usegrasshopper.com/view/)
